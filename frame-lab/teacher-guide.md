# 4D 구조 연구실 운영 안내

명세의 부품·조립 단계·안전 안내가 학생 화면의 단일 출처입니다. 변경된 학교 세트는 명세 담당자가 검토합니다.

모둠당 준비: 7cm 파랑 봉 14개, 10cm 노랑 봉 8개, 3발 연결발 5개, 6발 연결발 5개(여분 포함). 조립에는 7cm 봉 12개, 10cm 봉 최대 6개, 연결발 각 4개를 씁니다. 종이 모형, 12×12cm 종이 받침판, 실 40cm, 교사가 총질량 50g 이하를 확인한 추 주머니, 자, 고정할 연필, 종이테이프, 기록표와 추 아래 받침을 준비합니다. 최종 명세의 화면 부품표를 함께 확인합니다.

틀-연필 거리 20cm, T1에서 책상 면의 연필로 내려가는 실의 기울기, 위에서 본 +x 방향을 변형 전 같게 시작합니다. 변형 중 실 각도는 달라질 수 있습니다. 추 바로 아래에 받침을 두어 낙하 거리를 2cm 이하로 합니다. 이 힘은 수평이 아니라 아래로 기울어진 힘이며 화면에서 힘을 계산하지 않습니다.

40분 흐름: 문제 만나기 4분 → 예상·안전 3분 → 상자 틀 조립 9분 → 보강 0·2·4·6개 비교 11분 → 하나씩 빼는 재설계 8분 → 설명 고치기 5분.

M1은 각 조건 3회, M2는 조건 행을 추가하면서 각 조건 2회 측정합니다. 예상 입력 후 측정 표가 열립니다. 관찰과 설명을 분리해 적고, 종이 모형 접촉·손상·원상 복원 여부도 기록합니다. 프레임은 종이 모형 지지틀이며 실제 유물 운반 장치의 성능을 증명하지 않습니다. 실제 유물·귀중품, 불·열을 사용하지 않습니다. 추 아래에 발을 두지 않고 교사가 추 낙하와 책상 고정을 확인합니다.

화면은 명세의 조립 기하만 보여 줍니다. 밀림을 시뮬레이션하거나 값을 만들어 주지 않습니다. 기록은 이 기기의 `cons-lab:frame`에 저장되며 기존 수업·탐험과 분리됩니다. JSON·CSV를 내려받아 보관합니다.

교실에서는 단일 `dist/index.html`의 `?mode=frame`를 씁니다. 이 폴더의 `index.html`은 HTTP 개발·공식 게이트용이며 JSON을 읽습니다. 메인 앱은 동일 명세와 렌더러를 빌드에 내장하여 오프라인으로 실행합니다.
