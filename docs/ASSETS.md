# 에셋·출처와 사용 경계

| 에셋 | 구현 | 출처·권리 | 한계 |
|---|---|---|---|
| 여신상·꽃병·가면·숭례문·석탑 개념 그림 | `src/ui/art.ts` SVG | 이 프로젝트에서 직접 작성 | 학습용 재현 그림. 실측 도면·박물관 사진이 아님 |
| 연습 사건·일반 기록 카드 | 같은 SVG 모듈 | 직접 작성 | 실제 현장 사진 아님 |
| 문화유산 고르기 카드 | 재사용 개념 SVG | 직접 작성 | 지역 유산의 정확한 형태를 복원한 도면 아님 |
| 녹·접착 표면·칠 격자·층 블록 | `src/labs/labHost.ts`, CSS | 직접 작성 | `labs.config.json` 수식을 시각화한 설명 모델 |
| 꽃병 조각·작은 조각 | `src/labs/models.ts` | d3-delaunay(ISC), seedrandom(MIT) 기반 직접 생성 | 고정 시드의 볼록 실루엣 분할. 실제 꽃병 파편 형상 아님 |
| 전문가·원칙 기호 | 콘텐츠 JSON과 시스템 문자 | 원본 설계 기호 | 색 없이도 분야·결과 구분 가능 |
| 매뉴얼 QR | qrcode-generator(MIT) | 교사가 입력한 공유 주소로 기기 내 생성 | 공유 주소가 없는 경우 인쇄 안내 표시 |
| 글꼴 | 시스템 한글 글꼴 | 외부 다운로드·폰트 재배포 없음 | 기기에 따라 글자 모양 차이 |

실존 인물 사진, 박물관 소장품 이미지, 외부 질감 파일, 외부 플러그인 설치를 사용하지 않았다. 실물 기준 사진은 제공되지 않아 표시하지 않는다. 역사 문구와 출처는 제공된 `data/*.json`을 유지했다.
# 몰입 확장 자산

탐험 공간·작업대·유산 상징·아바타·연구원·나무는 직접 구성한 Three.js 기본 도형입니다. 표지판은 CanvasTexture와 시스템 글꼴로 그립니다. 참고 사이트의 코드·이미지·모델을 복제하지 않았습니다. 실제 유물이나 연구소의 정밀 복원 도면이 아닙니다. 미술관 참고 URL은 404였으며 그 사이트의 공간을 관찰했다고 주장하지 않습니다.

Three.js는 npm 의존성으로 번들한 MIT 라이브러리입니다(`node_modules/three/LICENSE`). 4D 뷰어는 승인된 `inquiry-science-webapp/assets/4d-viewer/` 템플릿에서 출발해 프로젝트 안에서 확장했습니다. 명세는 Claude 소유의 `frame-lab/4d-frame-spec.json`을 그대로 읽으며 메인 앱과 독립 연구실이 같은 렌더러를 사용합니다.
