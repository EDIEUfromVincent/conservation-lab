## 0. 공통 원칙
- **POE**: 실습 전에 팀별 예측을 잠근다(S12) → 실습으로 관찰(S13) → 결과 패널에 "예측 vs 결과"를 나란히 보여주고 설명은 말로 한다.
- **상태 기반 결과**: 결과는 정해진 '정답'이 아니라 아래 모델로 계산한다. 같은 시드면 항상 같은 결과(공정성·재현성).
- **모델 값은 설명용 근사값**이다. 실제 물리 상수가 아니다. 교사 패널에 이 사실과 근거(정성적 출처)를 표시한다.
- **실물 기준 사진(선택)**: `assets/pilot/labN_*.jpg`가 있으면 [실물 사진 보기] 버튼으로 시뮬레이션 옆에 띄운다.
- **빠른 모드**: 80분 프로필 기본. 단계 수·시간을 줄인다(매개변수 `quick`).
- **대체 증거**: 실습이 실패하거나 시간이 없으면 `lab.fallbackEvidence` 문구 카드로 대신한다.
- 조작은 교사 화면에서 교사(또는 나온 학생)가 마우스로 한다. 팀은 말로 지시한다.
- 매개변수의 원본은 `data/labs.config.json`.

```

## 실습 1. 두 금속이 맞닿으면? (사건 1, 주도: 금속)
**목적**: 서로 다른 금속이 물·소금과 함께 맞닿으면 한쪽(철)이 빨리 녹슨다는 것을 관찰 → c1d2(철 뼈대 결정)의 근거.

**예측(S12)**: `rank` — "3일 뒤 어느 못이 가장 많이 녹슬까요?" [쇠못만 / 쇠못 + 구리선 / 쇠못과 구리선 사이에 테이프]

**화면**
```
┌───────────────────────────────┬──────────────────────┐
│  [컵1]      [컵2]      [컵3]   │ 녹 정도 (0~100)       │
│  쇠못       쇠못+구리   쇠못|테이프|구리 │ 컵1 ████░░ 39     │
│   🪣          🪣         🪣     │ 컵2 ████████ 78   │
│                               │ 컵3 ████░░ 39     │
│  시간 ◀━━━━━●━━━━▶ 3일        │                      │
│  [1년 뒤 상상해 보기]          │ 순위: 2 > 1 = 3       │
└───────────────────────────────┴──────────────────────┘
```
**조작**: 시간 슬라이더(0~3일), [1년 뒤 상상해 보기] 버튼(상상 모델 표시), (보너스) [새 뼈대 시험] — 스테인리스 + 테플론 막 조건 컵을 하나 더 띄움.

**모델**
```
녹(t) = 100 × k × (1 − e^(−t/τ))      t: 일, τ = 2.0
k: 쇠못만 0.5 / 쇠못+구리선 1.0 / 테이프로 떼어 놓음 0.5 / 스테인리스+막 0.03
```
- 시각화: 못 위 녹 질감(사전 생성 PNG)의 불투명도 = 녹/100. 구리선과 닿은 부분부터 녹이 퍼지게(마스크를 접점 중심 원형으로 확대).
- 컵1과 컵3이 거의 같다는 점이 핵심 관찰: "구리와 떨어뜨리면 그냥 못과 같아진다" → '사이에 막을 끼운다'의 근거.

**측정 출력**: `rust_bare`, `rust_copper`, `rust_insulated`, `rank`(문자열), `predictMatch`(팀별).

**빠른 모드**: 슬라이더 대신 [3일 뒤 보기] 버튼 하나.

**대체 증거**: "구리선을 감은 못이 가장 많이 녹슬었어요. 테이프로 떼어 놓은 못은 그냥 못과 비슷했어요."

**교사 노트**: 실물 실험을 할 경우 아연 도금 못은 쓰지 않는다(녹이 거의 안 생김). 도금하지 않은 철못 + 소금물 + 구리선.

**완료 기준**: 같은 입력에서 값이 항상 같다. 순위가 `copper > bare ≈ insulated`로 나온다(단위 테스트).

## 실습 2. 붙이기 전에 기록하라 (사건 2, 주도: 유리)
**목적**: 기록 없이 맞추기와 기록하고 맞추기를 비교 → 기록·가조립의 가치. 작은 조각을 버리면 되돌릴 수 없음.

**예측(S12)**: `choice` — "기록 없이 섞인 조각을 1분 안에 다시 맞출 수 있을까요?" [다 맞춘다 / 절반쯤 / 거의 못 맞춘다]

**화면**
```
┌───────────────────────────────┬──────────────────────┐
│   꽃병 윤곽(점선)              │ 1회: 기록 없이        │
│   ┌──┐  조각들이 흩어져 있음    │   맞춘 조각 4/10, 60초 │
│   │  │   ▢ ▢ ▢ ▢ ▢           │ 2회: 기록하고         │
│   └──┘   ▢ ▢ ▢ ▢ ▢  · ·(작은조각)│   맞춘 조각 10/10, 34초│
│ [번호 붙이기] [사진 찍기] [섞기] │ 작은 조각: 2개 보관 ✓  │
│ 🗑 작은 조각 버리기             │ [사진 기록 보기]       │
└───────────────────────────────┴──────────────────────┘
```
**흐름**
1. **1회(기록 없이)**: 완성된 꽃병 → [섞기] → 60초 동안 끌어서 맞추기(회전 없음, 스냅 허용 오차 내면 딱 붙음) → 맞춘 개수·시간 기록.
2. **2회(기록하고)**: 다시 완성 상태 → [번호 붙이기](조각에 번호 표시) → [사진 찍기](번호가 보이는 축소 사진이 오른쪽에 고정) → [섞기] → 기록을 보며 맞추기 → 개수·시간 기록.
3. 작은 조각 2개는 맞추기 어렵게 작다. 화면 구석의 휴지통에 끌어 넣으면 사라지고 완성품에 구멍이 남는다(되돌릴 수 없음). 버리지 않고 '보관함'에 넣을 수도 있다.

**모델**: 보로노이 분할(`d3-delaunay`)로 꽃병 실루엣 다각형을 N개 조각으로 자른다(시드 고정). 작은 조각은 가장 작은 셀 2개를 다시 쪼개 만든다. 스냅: 조각 중심과 원래 위치 거리 ≤ 허용 오차면 고정.

**측정 출력**: `r1_correct`, `r1_seconds`, `r2_correct`, `r2_seconds`, `chips_discarded`.

**빠른 모드**: N=6, 1회 40초, 2회는 번호·사진 자동.

**대체 증거**: "기록 없이 맞출 때보다 번호와 사진을 남겼을 때 훨씬 빠르고 정확했어요."

**완료 기준**: 같은 시드에서 조각 모양이 같다. 조각이 서로 겹치지 않는다. 터치·마우스 모두 끌기 가능.

## 실습 3. 되돌릴 수 있는 접착제 찾기 (사건 3, 주도: 접착)
**목적**: 접착제 × 도구 조합에 따라 '떨어짐 / 흠집 / 남은 자국 / 걸린 시간'이 달라짐을 측정 → c3d2·c3d3의 근거.

**예측(S12)**: `rank` — "어떤 접착제가 흔적 없이 가장 잘 떨어질까요?" [밀랍 / 밀가루 풀 / 투명 테이프 / 강력 접착제(에폭시)]

**화면**
```
┌───────────────────────────────┬────────────────────────────┐
│  [금빛 가면 조각 + 수염]        │ 결과 표                     │
│        ░░(접착 부위)           │ 접착제  도구  떨어짐 흠집 자국 시간│
│                               │ 밀랍    나무   ✓    0   낮음 2일│
│ 접착제: ◉밀랍 ○풀 ○테이프 ○에폭시 │ 에폭시  금속   ✗    3   높음 9일│
│ 도구:   ◉나무 막대 ○금속 주걱    │ 에폭시  나무+데움 ✓  0  중간 28일│
│ ☐ 살짝 데우기                  │                            │
│ (접착 부위를 문질러 떼기)       │                            │
└───────────────────────────────┴────────────────────────────┘
```
(위 결과 표의 숫자는 화면 예시이며, 실제 값은 아래 모델이 계산한다.)

**조작**: 접착제·도구·데우기 선택 → 접착 부위를 문지르는 끌기 동작(한 번 = 1회). 진행 막대가 100%가 되면 떨어짐. 흠집은 영구 표시(되돌리기 불가, [다음 조합]을 눌러도 같은 가면이면 남게 할지 교사 옵션: 기본은 조합마다 새 가면).

**모델**
```
1회 = 접착 부위 위로 pxPerStroke(120px)만큼 문지른 거리
진행(회당) = base × reversibility × 도구힘 × (데우기 && warmSensitive ? warmMultiplier : 1)
흠집 수   = ceil(회수 × max(0, 도구경도 − 표면경도) × scratchRate)   (금속 도구는 한 번만 닿아도 흠집 1)
최대 회수 = maxStrokes(60). 넘으면 "시간이 너무 오래 걸려 떼지 못했어요"
남은 자국 = residue (0~1 → 낮음/중간/높음)
걸린 시간(일) = 회수 × daysPerStroke
```
- 매개변수: base 0.15, warmMultiplier 2.6, daysPerStroke 0.7. 밀랍 rev 0.9·res 0.2, 밀가루 풀 rev 0.85·res 0.1, 테이프 rev 0.6·res 0.5, 에폭시 rev 0.064·res 0.8(데우면 물러짐). 나무 경도 0.2·힘 1, 금속 경도 0.9·힘 2, 금 표면 경도 0.35.
- 이 값으로 계산하면: 밀랍+나무 8회(약 6일)·흠집 0 / 에폭시+나무+데움 41회(**약 29일**, 실제 '4주 넘게'와 맞춤)·흠집 0 / 에폭시+금속 53회·흠집 15 / 차가운 에폭시+나무는 60회 안에 떨어지지 않음.
- 금속 도구는 빨리 진행되는 듯 보이지만 반드시 흠집이 생긴다. 흠집 없이 에폭시를 떼는 길은 '데우고 나무 도구로 오래'뿐이다.

**측정 출력**: 조합별 `{adhesive, tool, warm, removed, scratches, residue, days}` 배열.

**빠른 모드**: 조합 3개만(밀랍+나무, 에폭시+금속, 에폭시+나무+데움), 진행 ×2. 화면의 '걸린 일수'가 바뀌지 않도록 daysPerStroke도 ×2.

**대체 증거**: "밀랍은 나무 막대로 금방 떨어졌고 흠집이 없었어요. 에폭시는 금속 주걱으로 긁으면 흠집이 났고, 데워서 나무로 떼면 흠집은 없지만 아주 오래 걸렸어요."

**완료 기준**: 금속 도구 + 금 표면 조합은 접착제와 상관없이 흠집 ≥ 1, 나무 도구는 0(단위 테스트). 에폭시는 어떤 조합이든 다른 접착제보다 오래 걸린다. 흠집 0으로 떨어지는 에폭시 조합은 '나무 + 데움'뿐이고 걸린 시간은 약 4주(29일).

## 실습 4. 테이프로 박락 재기 (사건 4, 주도: 페인트)
**목적**: 칠이 두껍거나 성질이 다른 풀을 번갈아 쓰면 더 많이 벗겨진다는 것을 숫자로 측정 → c4d1의 근거. (근거: 숭례문 복원 단청 연구 — 도막이 두껍고 서로 다른 교착제를 교차 사용하면 박리·박락 발생률이 높음)

**예측(S12)**: `rank` — "테이프 시험에서 어떤 칠이 가장 많이 벗겨질까요?" [얇게 한 겹 / 두껍게 한 겹 / 같은 풀 얇게 세 겹 / 다른 풀 번갈아 세 겹]

**화면**
```
┌───────────────────────────────┬──────────────────────┐
│ 시료 4개(나무판 위 색칠)        │ 벗겨진 칸 수 (25칸 중) │
│ [S1] [S2] [S3] [S4]           │ S1 ▌ 1                │
│ 각 시료에 5×5 격자             │ S2 █████ 9            │
│ 말리기 ◀━━━━━━━━●▶ 100%        │ S3 ██ 3               │
│ [테이프 붙이기] → [꾹 누르기] → [떼기] │ S4 ██████ 11       │
│ 학생 예상 칸 수 입력: [  ]       │                      │
└───────────────────────────────┴──────────────────────┘
```
**흐름**: 시료 선택 → 말리기 100% 확인(덜 마르면 "다 마른 뒤에 시험해요" + 번짐 표시, 측정 무효) → 테이프를 격자 위로 끌기 → 1초 누르기 → 위로 끌어 떼기 → 벗겨진 칸이 테이프에 붙어 올라감 → 팀이 센 칸 수를 교사가 입력 → 실제 수 공개 → 막대그래프 누적.

**모델**
```
p = clamp(base + 0.30×두꺼움 + 0.35×다른풀교차 + 0.03×(겹수−1), 0, 0.9),  base = 0.04
벗겨진 칸 수 = Math.round(p × 25 + 1e-9)   (부동소수 오차 대비. 어느 칸인지는 시드로 고정)
S1 얇게1겹: p=0.04 → 1   S2 두껍게1겹: 0.34 → 9   S3 같은풀3겹: 0.10 → 3   S4 교차3겹: 0.45 → 11
```
**측정 출력**: `s1`~`s4` 벗겨진 칸 수, 팀별 예상과의 차이.

**빠른 모드**: S1·S2·S4만, 말리기 자동.

**대체 증거**: "다른 풀을 번갈아 칠한 시료가 가장 많이 벗겨졌고, 두껍게 칠한 시료가 그다음이었어요."

**교사 노트**: 실제 도장 업계의 테이프 접착력 시험(격자 시험)을 단순화한 활동. 실물로 해 볼 때 젤라틴은 아교와 같은 동물성 풀이라 안전하다. 시료 ④가 실제로 더 벗겨지는지 미리 확인.

**완료 기준**: 순서 `S4 > S2 > S3 > S1`(단위 테스트). 덜 마른 시료는 측정되지 않는다.

## 실습 5. 증거가 있는 데까지만 (사건 5, 주도: 접착 / 보조: 금속)
두 부분으로 나눈다. 흐름에서 `lab:A`, `lab:B`.

### A. 보강하고 100년 뒤 떼어 내기 (c5d1의 근거)
**예측**: `choice` — "100년 뒤, 원래 돌을 다치지 않고 떼어 낼 수 있는 보강은?" [점토 / 콘크리트 / 둘 다 / 둘 다 아님]

**화면**: 무너진 서쪽 면이 있는 6층 탑(블록 격자). 보강재 선택(점토 / 콘크리트) → 무너진 면을 칠하듯 채우기 → [100년 뒤] → 콘크리트는 균열이 퍼지고 탑이 흔들림 표시, 점토는 조금 부서져 보수가 필요하다는 표시 → [보강재 떼어 내기] 클릭 반복.

**모델**
```
점토:     removeSteps 3,  원래 블록 손상 0,  100년 뒤 상태 "약해짐(자주 갈아 줘야 함)"

### B. 증거 카드로 다시 쌓기 (c5d2의 근거)
**화면**: 빈 탑 터 + 층 블록 9개 + 증거 카드 6장(1~6층: 옛 사진 느낌 일러스트·도면·남은 돌). 층을 올리려면 그 층의 증거 카드를 블록에 끌어다 붙여야 한다. 7~9층은 카드가 없어 '상상 모드'로만 올릴 수 있고, 점선 윤곽 + "근거 없음" 표시.

**측정 출력**: `floorsWithEvidence`, `floorsImagined`.

**대체 증거**: A "콘크리트는 떼는 데 오래 걸리고 원래 돌을 상하게 했어요. 점토는 쉽게 떨어졌지만 자주 갈아 줘야 해요." B "1~6층은 증거 카드가 있었지만 7~9층은 없었어요."

**완료 기준**: 콘크리트 제거 시 손상 블록 3개, 점토 0개(단위 테스트). 증거 없는 층은 실선으로 올라가지 않는다.
