## 참조 검증

`node tools/validate-scenario.mjs`: 종료 코드 0, 오류 0, 경고 1. 경고는 실제 AI 캡처 답변 미입력이다. 이 검사는 그래프 참조 검사이며 아직 Ajv 스키마 검증이나 역사 출처 재검증을 의미하지 않는다.

- 본 사건 5개, 연습 사건 1개. 본 사건 결정 11개, 선택적 결정 3개(c2d1, c3d3, c4d2).
- 원칙 분포: 조사 3, 원인 2, 되돌림 4, 최소 개입 1, 증거 1.
- 전문가 주도: 금속 1, 유리 1, 페인트 1, 접착 2.
- 프로필 시간 합계 120분/80분. 80분 쉬는 시간은 사건 2 뒤이며 수업 시간 합계에 포함하지 않는다.

## 구현 시 충돌 해석

1. 재선택 횟수는 docs/04의 '사건당'보다 엔진 명세 docs/05의 **결정당 1회**를 적용한다.
2. S25 순위/합계 노출은 기본 비공개. 건강도는 사건 중 팀별 표시, 최종 합계는 교사 패널에 둔다.
3. 시나리오 JSON이 수업 내용의 원본이다. docs/07의 전이 예시 '비석'과 JSON의 '놋그릇'이 다르므로 JSON을 따른다.
4. 실습 예시 와이어프레임의 숫자를 복사하지 않고 config의 수식으로 계산한다. 에폭시+나무+데움은 일반 모드 41회, 28.7일이며 빠른 모드의 마지막 부분 회차를 제한해 일수 왜곡을 막는다.
5. singlefile은 file://로 직접 열어 네트워크 없이 검증한다. 서비스 워커를 요구하는 일반 웹앱 패턴은 이 배포 형태에 적용하지 않는다.
6. CSP는 배포에서 외부 연결을 막되 Vite 개발 HMR 연결과 충돌하지 않도록 개발/배포를 구분한다.
7. 예측 입력은 자동 선택하지 않는다. 예측 잠금 전에 실습 측정값이 노출되지 않도록 한다. 근거가 없는 팀/미투표 팀을 실제 응답으로 기록하지 않는다.

## 사실·교사 입력 경계

- 영상 URL, 공유 매뉴얼 URL, AI 캡처, 실물 사진은 비어 있다. 임의 영상·AI 답변·사진을 생성하지 않는다.
- 숭례문 최신 현황은 2022년 자료 기준이며 '현재'로 단정하지 않도록 기준 시점을 표시한다.
- 여신상 초록 표면 유지의 1차 출처 확인은 원본 문서에서도 미결 사항이다.
- 실습 모델은 설명용 근사값이다. 접착제 일반 모델을 특정 실제 보존용 제품의 측정 결과로 설명하지 않는다.
- 역사 출처 링크가 존재한다는 검증과 그 출처 내용의 사실 검증은 구분한다.

## 테스트 우선순위

- 팀별 감점과 반 경로 독립, 팀에만 지연 결과가 있을 때 지연 단계, 중복 확정/중복 지연의 감점 방지, 재선택 1회, 건강도 0 하한, 연습 사건 무점수.
- 두 선택지뿐인 c3d3에서 C 입력 차단, 동점 교사 결정, 투표 0개 확정 방지, 공개 이후 뒤로 가기 금지, optional 건너뛰기 기록.
- 실습 수식·시드 재현·조각 분할/스냅·건조 전 측정 방지·근거 없는 층 점선.
- 저장 실패에도 진행, 새로고침 복원, JSON 전체 구조 검증 후 원자적 복원, 사용자 텍스트 HTML 실행 차단, CSV 수식 주입 방지.
- 키보드 전체 진행, 네트워크 0건, 단일 HTML 5MB 이하, 모바일 매뉴얼, 프로젝터 3해상도, 교사 노트가 없는 A4 인쇄.

개발 서버는 Grok 담당이다. Codex 테스트는 가능하면 빌드 파일을 직접 열어 중복 서버를 피한다.
