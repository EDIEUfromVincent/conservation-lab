# 보존과학자의 하루 · 교사용 빠른 안내

설계 근거는 [docs/12-redesign.md](12-redesign.md)를 따른다. 학생은 '한빛 보존연구소'(가상)에 첫 출근한 신입 보존과학자가 되어, 아침 영상 → 저녁에 맡을 의뢰 고르기 → 실제 사건 파일 5개 → 연구 일지로 알고리즘 찾기 → 저녁 의뢰를 해결하는 프로그램 만들기·시험·고치기 → AI 답 점검 → 퇴근 보고 순서로 하루를 보낸다.

## 수업 열기

1. `npm run package:classroom` → `classroom/` 폴더가 생긴다(`index.html` + `video/` 영상 파일). 폴더째 교실 PC나 USB에 복사해 `index.html`을 Chrome에서 연다. 인터넷 없이 작동한다.
   - 영상 파일이 없으면 화면에 안내가 나오고, 시작 화면의 '영상 주소'에 넣은 주소를 새 탭으로 열 수 있다.
   - 자막 없는 영상(`conservation-seedance-55s-plain.mp4`)이 없으면 1회차에도 자막 판이 재생된다. 질문형 해요체 자막으로 다시 합치는 일은 docs/12 §4.1을 따른다.
2. 120분 연속 또는 80분 프로필을 고른다. 80분은 빠른 실습이 기본이며 사건 파일 3 뒤에 '점심시간'(1차시 끝) 화면이 나온다. 두 프로필 모두 선택적 결정(c2d1, c3d3, c4d2)은 건너뛰는 것이 기본이다. 시간이 남으면 시작 화면이나 교사 도구에서 끈다.
3. 학생 이름은 어디에도 넣지 않는다. 팀 번호(1~4)와 손든 학생 수만 기록한다.
4. 저장된 수업이 있으면 **이어하기**를 고른다. 재설계 이전 형식의 기록은 이어할 수 없다는 안내가 나온다.

### AI 조수 점검 준비

- **수업 중(권장)**: S30에서 의뢰가 정해지면 교사 도구(T)에 'AI에 물을 질문'이 나온다. 별도 기기·탭에서 실제 생성형 AI에 그대로 묻고, 모델명·날짜·답변 전문을 교사 도구에 붙여 넣는다. 앱은 AI에 접속하지 않는다.
- **미리 받아 두기**: `data/scenario.json` → `aiCheck.capturedAnswers`에 경복궁 담장 낙서 질문의 실제 답을 넣어 두면, 붙여 넣은 답이 없을 때 그 답으로 점검한다(이때 H 키로 실제 처리 과정을 보여 줄 수 있다).
- 둘 다 없으면 화면에 '실제 AI 캡처 답변이 없어요'가 나온다. 답을 지어내지 않는다.

## 교사만 보는 것

- 사건 결정의 숨은 원칙(P1~P5)과 결과는 교사 도구에만 보인다. 학생 화면에는 S21 비교 전까지 원칙 이름이 나오지 않는다(E2E로 검사).
- 실습 수치는 학습용 근사값이며 실제 물성 측정값이 아니다.
- 숭례문 현황은 2022년 보도 기준이다. 수업 전 최신 자료를 확인한다.

## 3D 미션(사건 파일 5개)

시작 화면의 노란 '3D 미션' 버튼 또는 `?mode=mission`으로 사건 목록을 연다. 사건 카드를 누르거나 숫자 1~5를 누른다. 사건마다 무대가 다르다(1 섬 · 2·3 박물관 전시실 · 4 서울 광장 · 5 익산 들판, 모두 블록으로 새로 그린 모형).

1. **사건 발생** → 주도 전문가에게 매뉴얼을 펼치라고 한다.
2. **지도**: 오른쪽 패널에 조사할 곳과 처리 결정이 있다. 연구원은 조이스틱(왼쪽 아래)이나 방향키·WASD로 직접 걷고, 건물 가까이 가면 'E · 조사하기'가 뜬다. 패널의 장소를 눌러도 걸어간다. 결정은 필요한 사실을 알아내야 열리고, 어떤 장소는 앞 결정을 마쳐야 열린다(예: 사건 3 '수염 이음매', 사건 5 '기록 보관실').
3. **단서('?')**: 카드 A~D 중 단서를 설명하는 카드를 반이 고른다. 카드는 세 가지다. 매뉴얼 '단서 → 원인 → 처리' 표의 줄, 매뉴얼 '꼭 기억해요', 앞 사건에서 받은 **연구 일지** 카드(예: 사건 3은 사건 2의 '번호를 달고 사진으로 남겼어요'로 푼다). 맞으면 '알아낸 사실'이 된다. 다른 카드를 고르면 연구실장이 다시 볼 곳을 짚어 준다(감점 없음). 재촉하는 말·광고·짐작처럼 **증거가 아닌 단서**도 섞여 있다.
4. **분석실**: 그 사건의 실습을 하고 관찰 기록을 저장하면 결과가 단서가 된다(사건 5는 실습 1부 '보강재 떼어 내기').
5. **처리 결정**: 길 A~C + 근거가 된 사실 하나 → 결과(✓ 해결 · △ 나빠짐 · ✕ 되돌리기 어려움) → 실제 역사 → 연구 일지 카드 → 미션 완료 → '다음 사건 파일'.

키: 다음(PageDown/Space)은 노란 테두리가 있는 다음 할 일을 누른다(미션 완료 화면에서는 다음 사건으로). 걷기 방향키·WASD, 조사하기 E, 단서 카드 A~D, 결정 길 A~C, 근거 1~9, 지도에서 장소·결정 번호, 뒤로 Esc. 기록은 사건마다 이 기기의 `cons-lab:mission:case1`~`case5`에 저장되며 본 수업 기록과 섞이지 않는다. 3D를 띄울 수 없는 컴퓨터에서는 그림과 조이스틱 없이 같은 흐름으로 진행된다.

## 심화 자료(2시간 수업과 분리)

연구소 탐험(3D)과 4D 프레임 구조 연구실은 기본 빌드에 들어 있지 않다. 따로 쓰려면 `npm run build:extras`로 빌드하고 `?mode=expedition`, `?mode=frame`으로 연다. 4D 프레임 랩의 학생 문구는 아직 초5 해요체로 다시 쓰지 않았다.
