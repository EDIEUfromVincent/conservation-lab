# 07. 콘텐츠: 사례 5개 + AI 점검 + 전이

학생 화면 문구의 원본은 `data/scenario.json`이다. 이 문서는 **사실 근거, 출처, 교사 노트**를 정리한다. 사실을 고칠 때는 이 문서와 JSON을 함께 고치고 `fact-checker`로 대조한다.

## 연습 사건 — 학급 문집에 물을 쏟았어요
- 목적: 투표·근거 태그·결과 공개 조작 익히기. 점수 없음.
- 선택: A 뜨거운 드라이기로 빨리 말림(△ 종이가 쭈글쭈글) / B 사진 찍고 키친타월로 살살 눌러 물기를 뺀 뒤 그늘에서 말림(✓) / C 그냥 덮어 둠(△ 곰팡이).

## 사건 1. 자유의 여신상의 녹 (미국, 1980년대)
**주도 금속 / 보조 접착·페인트 / 실습 1 / 단계: minimal, rootCause**

### 핵심 사실
- 1980년 정밀 조사에서 철 뼈대(armature bars)가 구리 겉면·받침과 갈바닉 반응을 일으키고 있음이 밝혀짐. 물이 전해질 역할을 하며 구리와 닿은 곳마다 철이 부식. 녹이 부풀어 리벳을 겉면 밖으로 밀어냄. (NPS 1986)
- 1911년 물이 새자 내부에 역청(타르) 페인트를 칠함. 1937~38년 일부 뼈대 교체. 1980년에는 약 1,800개 뼈대 중 3분의 2가 심하게 부식. (NPS 1986)
- 19세기 제작자들도 갈바닉 반응 가능성을 알아, 셸락을 먹인 석면 펠트를 사이에 끼운 흔적이 있음. (NPS 1986)
- 1984~86년 복원: 뼈대를 저탄소 스테인리스강(316L 등)으로 교체하고 테플론으로 구리와 절연. 오른발 샌들 바닥에 원래 뼈대 몇 개를 남김. (NPS 1986, ENR 1984)
- 바깥 초록색 녹(파티나)은 구리를 보호하는 층으로 보고 제거하지 않음. → **fact-checker로 1차 출처 재확인 권장**(널리 알려진 사실이나 위 두 출처의 인용 부분에는 직접 언급 없음).

### 결정 요약
| 결정 | A | B | C |
|---|---|---|---|
| c1d1 초록 겉면 | 녹을 벗겨 구릿빛으로 ✕ | 그대로 둔다 ✓ | 페인트로 가린다 △ |
| c1d2 철 뼈대 | 같은 철로 새로 △(50년 뒤, 재선택) | 스테인리스 + 사이에 막 ✓ | 페인트만 덧칠 △(약 25년 뒤, 재선택) — 1911년 실제 시도 |

### 교사 노트
- 오개념: "녹은 모두 나쁘다", "새것처럼 만드는 것이 보존이다".
- c1d2 C는 실제 역사(1911년 타르 페인트 → 1937~38년 교체)와 연결해 "옛사람도 겉만 고치는 실수를 했다"를 보여준다.
- 1980년대 결정에 철학적 질문: "100년 동안 생긴 초록색은 여신상의 일부일까?"

## 사건 2. 깨진 포틀랜드 꽃병 (영국, 1845 → 1989)
**주도 유리 / 보조 접착 / 실습 2 / 단계: investigate(선택적), reversible**

### 핵심 사실
- 기원전 30년~서기 25년 무렵 로마의 카메오 유리 꽃병. 1810년부터 영국박물관에 있음. (History of Information)
- 1845년 2월 7일 한 관람객이 진열장을 깨뜨려 꽃병이 80조각 넘게 부서짐. (World History Encyclopedia)
- 박물관 기술자 존 더블데이가 그해 9월까지 다시 붙임. 당시 훌륭한 솜씨로 평가. 접착제는 100년 넘게 버텼으나 점점 누렇게 변함. (Wikipedia: John Doubleday)
- 1948~49년 재복원(액스텔) 때 남은 작은 조각 37개 중 3개만 제자리를 찾음. 1986년쯤 이음매가 약해져 살짝 두드리면 달그락거림. (History of Information, Smithsonian MCI 초록)
- 1988~89년 재복원(나이절 윌리엄스): 해체 전 조각 위치를 사진·그림으로 기록. 이전 접착제가 모두 실패했으므로 박물관 보존과학자들이 여러 접착제의 장기 안정성을 시험한 뒤 선택. (History of Information)
- 1988년 재복원에 쓴 접착제의 종류에 대해서는 자료마다 설명이 다르다(노화 특성이 좋은 에폭시 / 자외선으로 굳는 고분자). **학생 화면에는 '오래 시험해서 고른 접착제'까지만 쓴다.**

### 결정 요약
| 결정 | A | B | C |
|---|---|---|---|
| c2d1 붙이기 전 (선택적) | 바로 붙이기 △ | 번호·사진·위치 기록 후 가조립 ✓ | 작은 조각 버리기 ✕ |
| c2d2 접착제 | 지금 가장 센 것 △(100년 뒤 누렇게) | 오래 버티는지 시험한 것 ✓ | 테이프 △ |

### 교사 노트
- 공정성 발문: "1845년의 기술자는 잘못한 걸까? 그때는 무엇을 몰랐을까?" → 정답 없음, 과거를 그 시대 지식으로 평가하는 태도.
- '86조각 퍼즐'은 실습 2와 바로 이어진다.

## 사건 3. 투탕카멘 황금 가면의 수염 (이집트, 2014 → 2015)
**주도 접착 / 보조 금속·유리 / 실습 3 / 단계: investigate, reversible, reversible(선택적)**

### 핵심 사실
- 약 3,300년 된 가면. 2014년 8월 수염이 떨어졌고 박물관 직원들이 에폭시로 서둘러 붙임. 삐져나온 접착제를 주걱으로 긁다가 흠집을 남김. (Live Science, AP/Fox News)
- 2015년 10월 독일·이집트 합동 팀이 복원 시작. 팀장은 유리·금속 전문 보존가. 먼저 3D 스캔으로 상태 기록. (National Geographic)

- 고대 이집트에서 흔히 쓰던 밀랍으로 수염을 다시 붙임. (National Geographic 2016)
- 복원 중 수염 안쪽에서 가면과 잇는 관(금관)이 새로 확인됨. 1946년에는 연납(soft solder)으로 붙였었음. (National Geographic, Live Science)

## 사건 4. 벗겨지는 숭례문 단청 (한국, 2008 → 현재)
**주도 페인트 / 보조 접착 / 실습 4 / 단계: investigate, rootCause(선택적)**

### 핵심 사실
- 2008년 2월 10일 방화로 무너진 숭례문은 5년 3개월 만인 2013년 5월 복원. 완료 5개월 만에 부실 논란, 가장 먼저 드러난 것이 단청. (텐아시아/PD수첩 2014)
- 2014년 감사원: 단청 책임자가 시공 중 아교가 흘러내리고 색이 흐려지자 사용이 금지된 화학접착제와 화학안료를 몰래 반입·사용해 단청 균열이 생기거나 심화. 공사 기한에 맞추려다 곳곳 부실. (서울신문 2014)
- 보존과학 연구: 사용된 안료 12종 중 호분·석간주를 뺀 10종이 인공안료. 도막 층이 두껍고 다른 물성의 교착제를 교차 사용하면 박리·박락 발생률이 높음. (보존과학회지 30(4), 2014)
- 2017년 6월 기준 목부재 6,700개소 중 647개소(9.7%)에서 박락. 2022년 보도 시점까지 재시공 못 함. 법원은 정부 책임을 20%로 판단. 전통 단청 기술의 맥이 끊긴 상황에서 정부가 무리하게 전통 기법을 고집했다는 지적. (머니투데이 2022)
- **수업 직전 최신 상황을 확인**해 `case4.history` 마지막 줄을 고친다.

## 사건 5. 콘크리트 옷을 입은 미륵사지 석탑 (한국, 1915 → 2019)
**주도 접착(보강) / 보조 금속 / 실습 5A·5B / 단계: reversible, evidence**

### 핵심 사실
- 백제 무왕 때 창건. 원래 9층으로 추정되나 무너져 6층 일부만 남음. (교보 스콜라 초록, 이광표 칼럼)
- 1915년 조선총독부가 위험하다고 판단해 무너진 1~6층의 세 면에 엄청난 양의 콘크리트를 덧붙임. 당시 최신 토목 재료. (이광표 칼럼)
- 1915년 수리에 철제 보강재(H빔)도 쓰임 — 국립익산박물관 전시(2020~21)에서 처음 공개. (전북일보)
- 1998년 정밀 구조 안전진단 → 콘크리트 부식·석재 균열로 붕괴 위험 → 1999년 해체 보수 결정 → 2001년 해체 시작 → 2019년 완료(약 20년). (전북일보, 경향신문, 이광표 칼럼)
- 9층 원형 복원은 역사적 고증과 학술적 근거 부족으로 불가능하다고 판단해 6층까지 복원. 근거 없는 복원은 문화재 가치를 잃고 세계유산 재심사에 문제가 될 수 있다는 설명. (한국경제 2015, 프레시안)

| c5d1 1915년, 무너지려는 탑 | 콘크리트로 단단히 △(80여 년 뒤) | 뗄 수 있는 나무 받침·쐐기 ✓ | 그대로 둔다 ✕ |
| (역사 합류) | 실제로는 A. 1998년 진단, 2001년 해체 시작 | | |

- c5d2는 토의형: 팀별 30초 주장 → 투표. 9층을 고른 팀의 논리("원래 9층이었다")도 존중하고 "그 9층의 모양을 무엇으로 알 수 있지?"로 증거 문제로 연결.
- 공정성 발문: "1915년 사람들은 잘못한 걸까? 오늘 우리가 쓰는 방법도 100년 뒤 누군가 떼어 내야 할까?"
- 일제강점기라는 역사적 맥락은 사실대로 언급하되, 수업의 초점은 '보강 재료의 가역성'에 둔다.
- 지명: 2024년부터 '전북특별자치도'. 학생 화면은 '전북 익산'으로 쓴다.

## AI 조수 점검 — 경복궁 담장 스프레이 낙서 (2023.12)
### 핵심 사실
- 2023년 12월 16일 새벽 경복궁 서쪽 담장(영추문 일대, 국립고궁박물관 쪽문 주변)에 붉은색·푸른색 스프레이 낙서. 이튿날 같은 방식의 추가 낙서. (데일리안, 허프포스트, 위키트리)
- 스프레이가 일부 담장 석재에 스며들어 원형 복구에 시간이 걸림. (데일리안)
- 보존처리 전문가들이 스팀 세척, 레이저 클리닝 등 화학적·물리적 방법을 병행. 강추위로 중단된 기간을 빼고 약 8일 작업, 19일 만에 가림막 제거(2024.1.4). (허프포스트, 서울신문)
- 2024년 4월 2차 보존처리: 아세톤을 바른 뒤 젤란검을 붓으로 붙여 미세하게 남은 흔적 제거. (머니투데이)
- 복구 비용 1억 원 이상으로 추산, 손해배상 청구 방침. (파이낸셜뉴스)

### 수업 운영
- 교사가 수업 전에 실제 생성형 AI에 `aiCheck.promptToAsk`를 묻고, 답변 전문을 **날짜·모델명과 함께** 넣는다. 답변을 지어내지 않는다.
- 학생은 알고리즘 5단계 체크리스트로 점검 → 실제 처리 공개.
- 낙서한 사람에 대한 이야기는 하지 않는다(미성년자 포함 사건). 초점은 '돌에 스며든 페인트를 어떻게 지웠나'.
