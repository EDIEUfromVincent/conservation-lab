# AIEDAP 지도안 · 실행판

내용 출처: `docs/02-lesson-flow-and-assessment.md`와 `data/scenario.json`. 성취기준 추가 확정 및 교실 효과 검증을 대신하지 않는다.

| 항목 | 내용 |
|---|---|
| 수업명 | 보존과학자의 하루: 선택이 문화유산의 운명을 바꾼다 |
| 대상 | 초등 5학년 영재 16명, 본 팀 4개 × 전문가 4분야 |
| 교과 | 사회·과학·실과 융합 |
| 시간 | 120분 연속 / 80분 두 차시 |
| 수업 유형 | AI 내용요소 연계형 |
| 학습 목표 | 손상 원인과 보존 원칙 연결, 예측·관찰 근거로 판단, 다섯 사례에서 알고리즘 도출, AI 답변 비판적 점검 |
| 성취기준 | 실과 [6실05-01]. 사회·과학 연계 코드는 교사 확정 |
| 도구 | 오프라인 단일 HTML, 전문가 매뉴얼, W1–W4, 팀별 A/B/C 카드 |
| AI 활용 | 실제 사전 캡처 답변만 점검. 앱 내부 AI 호출 없음 |

| 흐름 | 120분 | 80분 | 관찰할 증거 |
|---|---:|---:|---|
| 도입·영상·문화유산 선택 | 22분 | 12분 | W1: 보존과학자 인식, 지키고 싶은 이유 |
| 직소 전문가 학습·팀 구성·연습 | 15분 | 11분 | 전문가 퀴즈·설명 연습 |
| 사례 1–5: 예측→실습→선택→결과→역사 | 57분 | 45분 | 팀 예측, 실습 기록, 근거 태그, W2 |
| 공통 알고리즘 도출 | 8분 | 6분 | 우리 반 카드·원칙 비교 |
| AI 조수 점검 | 5분 | 3분 | 다섯 항목 예/아니오/미정 |
| 전이·성찰·마무리 | 13분 | 3분 | W3 선택 그래프, W4 성찰. 80분은 전이를 과제로 연장 가능 |

80분은 사건 2 뒤 쉬는 시간을 갖는다. 쉬는 시간은 수업 분 합계에 포함하지 않는다. 실제 흐름 순서는 JSON을 따른다.

| 평가 기준 | 상 | 중 | 하 |
|---|---|---|---|
| 증거 기반 판단 | 측정·매뉴얼을 연결하고 예측 차이를 분석 | 한 가지 근거로 선택 설명 | 도움을 받아 이유 말하기 |
| 원칙 일반화 | 공통 알고리즘을 새 사례에 적용·검증 | 2–3개 원칙을 새 사례에 적용 | 카드 도움으로 사례 연결 |
| AI 점검 | 빠진 단계와 근거를 찾아 보완 | 빠진 단계 찾기 | 도움을 받아 실제 처리와 비교 |
| 협업 | 분야 내용을 설명하고 근거로 응답 | 자기 분야 설명 | 매뉴얼 도움으로 일부 전달 |

지원은 말하기·짧은 글·교사 대필을 허용한다. 앱은 열린 설명을 자동 채점하지 않는다. 기능 테스트 통과는 수업 효과의 증명이 아니며, W1·W3 변화와 W2·W4, 실제 토의를 함께 평가한다.
