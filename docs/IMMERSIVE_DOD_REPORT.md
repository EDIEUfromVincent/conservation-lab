# 몰입 확장 구현·검증 완료 보고서

검증일: 2026-11-03, Asia/Seoul. 코드: Codex / 계획·명세: Claude / 서버: Grok. 통합 담당 Codex가 구현 범위를 정리한 뒤 추가 기능을 확장하지 않고 전체 회귀와 보고를 마쳤다.

## 결과물

`dist/index.html` **778,771바이트**(778.77 kB, Vite gzip 표시값 222.02 kB). JS·CSS·Three.js·데이터·절차적 도형을 포함한 단일 파일이며 **5 MiB 이하**다. 기존 CSP의 `connect-src 'none'`을 유지했다.

- `?mode=expedition`: 독자적인 low-poly/voxel 보존연구소, 이동 아바타, 팀 번호·작업복 색, 다섯 유산 작업대와 연구원, 근접 후 명시적 E/버튼 대화, 큰 방향 조작, DOM 현장 목록과 WebGL 대체 경로.
- 현장마다 자료 관찰 → 서로 다른 도구 기록 → 예상 → 기존 `labHost` 실제 조작 → 처치와 근거 → 결과·역사 연결 → 성찰·전시카드. 모형값을 실제 측정값과 구분한다. 지연 결과는 별도 버튼으로 공개한다. 처치는 재선택하지 않는다.
- `?mode=frame`: 승인된 명세와 `frame-lab/frame-viewer.js`를 동일하게 번들한다. 6개 조립 단계와 보강 0/2/4/6개 전환, 예상 후 M1 측정 표, M2 조건 행 추가·각 조건 2회 측정, 관찰·설명·한계와 이유, 독립 저장·내보내기를 제공한다.
- 수업 시작 화면에 두 진입 링크가 있다. 각 모드에서 기존 수업으로 복귀할 수 있다. 탐험 현장 목록에서도 같은 프레임 연구실을 패널로 연다.
- `cons-lab:current`, `cons-lab:expedition`, `cons-lab:frame`은 분리된다. 새 두 모드 모두 JSON·CSV 내보내기와 해당 활동만 초기화하는 경로를 제공한다. 로그인·채팅·백엔드·기기 간 동기화는 없다.

## 최종 통합 검증

실행 명령:

```sh
npm test && npm run build && npm run e2e && npm run gate:frame && node tools/check-hardcoded-text.mjs
```

전체 종료 코드 **0**. `pretest`는 콘텐츠 검증을, `prebuild`는 타입·콘텐츠 검증을 실행한다.

| --- | --- |
| TypeScript | 통과 |
| 콘텐츠·탐험 참조 검증 | 오류 0건, 기존 AI 캡처 미입력 경고 1건 |
| 단위 테스트 | **46개 통과**: 기존 38 + 신규 8, 5개 파일 |

E2E는 설치된 Google Chrome에서 빌드 파일을 `file://`로 실행했다. 탐험의 WebGL 검증은 SwiftShader 인자를 사용했다. 4D 공식 게이트는 Playwright Chromium을 사용하며 게이트 자체의 일시적인 localhost 서버로 독립 폴더를 검사한다. Grok 서버는 재시작하지 않았다.

신규 E2E가 실제로 확인한 것:

1. 다섯 현장 전체를 실제 UI로 조사·예상·실습·처치·전시까지 완주. 꽃병 두 회차 맞추기, 접착제 제거, 테이프 시험, 보강 제거와 층수 증거까지 수행했다. 저장 후 새로고침으로 다섯 카드가 복원되고 JSON 내려받기 내용을 확인했다.
2. 탐험의 **32개 결과**를 모두 표시하고 원본 결과 ID 집합과 대조했다. 이 검사는 실습 완료 상태를 주입한 분기 검사이며, 실제 실습 완주는 1번에서 별도로 검사했다. 기존 수업의 **35개 결과**는 연습 사건 3개를 포함한 기존 회귀 검사다.
3. 키보드 이동, 근접 후 E 대화, 패널 중 위치 유지, blur 후 이동 해제, CDP 터치로 큰 방향 버튼을 눌렀을 때 이동·놓았을 때 정지, 1024×768 태블릿 가로 화면과 reduced-motion 설정.
4. WebGL을 차단해도 DOM 목록만으로 실제 사건 1을 완주. 탐험 초기화가 교사·프레임 저장키를 보존함을 확인했다.
5. 프레임의 단계·보강 전환·키보드 회전, 예상 전 측정 잠금, M1 입력, M2 조건 추가와 두 반복값, 새로고침 복원, CSV 내려받기, 통합 담당 Codex가 추가한 ‘이 시험으로 알 수 없는 것과 그 이유’ 필드의 복원.
6. 기존 수업 → 탐험 → 복귀를 두 차례 반복하고 수업 설정이 유지됨을 확인했다. 프레임에서 복귀 후 PageDown 한 번이 INTRO 한 단계로만 진행됨을 확인했다.

탐험 완주 테스트는 HTTP 요청을 차단했고 외부 HTTP 요청·페이지 오류 모두 0건이었다. 프레임 테스트는 브라우저 오프라인 모드에서 열고 새로고침했으며 외부 HTTP 요청·페이지 오류 모두 0건이었다. 별도 `frame-lab/index.html`은 JSON을 읽는 HTTP 개발·게이트용이며, 교실 오프라인 지원 대상은 **메인 단일 HTML의 두 모드**다.

## 리뷰 반영

- 사진 기록을 연도·지역 배경 문장에서 유물의 실제 상태 설명으로 변경했다. `data/expedition.json`이 원본 `brief.lines[...]`를 참조하며 validator와 단위 검사로 참조를 확인한다. 제공 자료를 보는 활동이라는 한계도 표시한다.
- 다섯 실습의 요약·전시카드에 `rust_bare`, `main`, `trials` 같은 내부 키를 표시하지 않는다. 쇠못·구리선·절연 조건, 기간(일), 녹 발생 모형 지수(/100), 조각·초, 접착제·도구·흠집·남은 자국, 벗겨진 칸(/25), 보강재·제거 횟수·손상·근거가 있는 층으로 표시한다.
- 프레임 저장 오류 문구를 한국어로 수정했다. M2는 조건 행마다 밀림 1·2회, 모형·받침판 접촉·손상·복원 기록을 갖는다. 관찰과 설명을 분리했다.
- 통합 담당 Codex가 추가한 M1/M2의 한계·이유 필드를 유지했고, 저장 검증 허용 필드에도 반영했다.
- 통합 담당 Codex의 최종 문구 수정(같은 추, 변형 전 시작 각도만 같게 함, 변형 중 각도 변화, 모형·받침판 관찰, 봉만 표시하는 뷰어)을 보존했다. 최종 `dist/index.html`에 해당 문구가 포함됐음을 직접 확인했다.

## 계획 대비 선택·한계

통합 담당 Codex는 사용자 요청에 따라 최소 완결 루프·다섯 현장·태블릿·독립 저장·증거 기반 전시·4D 게이트를 필수로 정하고 부차 범위는 판단하도록 허용했다.

- 계획의 읽기 전용 실습 증거 카드 대신 **기존 실제 실습을 재사용**했다(사용자 요청에 따른 통합 구현 결정). 탐험은 통일된 예상→실습→처치 순서이며, 기존 교사 수업의 원래 순서는 보존했다.
- 도구는 사진 기록·확대 관찰·전문가 매뉴얼 3종을 바로 선택한다. 5종 도구 소지품 수집과 별도 도구대 퀘스트는 넣지 않았다. 서로 다른 도구 2개를 기록해야 진행한다.
- 태블릿은 큰 방향 버튼을 사용한다. 조이스틱/D-pad 전환은 미구현이다. 오른쪽 드래그 시점 조작과 선택적인 짧은 기록음을 제공한다. 기록음은 기본 꺼짐이다.
- 세계는 독자적인 작업대·표지판·연구원 중심 연구소다. 전시카드는 수첩으로 열람한다. 공간 액자 6개, 구조 연구실 자동 최소 보강 카드, 분야 선택 표찰, 별도 연구소 발표 보상은 미구현이다. 실제 측정의 성공 여부를 자동 판정하지 않는다.
- 프레임 M1 평균 자동 계산은 추가하지 않았다. 입력 원값을 보존하며 각 조건 3회 기록한다. M2는 최대 20개 조건 행을 추가할 수 있다.
- 학생 골격 라벨은 `src/expedition/labels.ts`, 자료 참조는 `data/expedition.json`, 역사·실습 원본은 기존 `data/*.json`에 둔다. 별도 kid-reader 검토 기록은 생성하지 않았다. 수행하지 않은 독립 문구 검토를 주장하지 않는다.
- 새 모드는 내보내기와 기기 내 자동 복원을 제공하며 별도 파일 가져오기는 제공하지 않는다. 기존 수업의 검증된 가져오기 동작은 유지한다.
- 코드에 RAF·리스너·기하·재질·텍스처 정리 경로를 구현했고 두 번의 복귀를 검사했지만 **메모리 누수가 없다는 실측은 하지 않았다**. 실제 태블릿 하드웨어·Safari·교실 학습 효과·실물 프레임 성능은 검증하지 않았다.

기존 AI 캡처·영상·매뉴얼 공유 주소와 최신 역사 사실 확인 등 교사 준비 항목은 [기존 완료 보고서](DOD_REPORT.md)를 따른다. 프레임은 학교 세트와 실물 준비물·안전을 교사가 확인해야 한다.
