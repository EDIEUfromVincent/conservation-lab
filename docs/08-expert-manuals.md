# 08. 전문가 매뉴얼 4종

원본: `data/manuals.json`. manual 모드(M01·M02)와 print 모드(P01)가 같은 데이터를 쓴다.

## 1. 설계 원칙
- **서로 다른 정보**: 네 매뉴얼은 겹치지 않는 핵심을 담는다. 공통인 것은 '보존과학자의 원칙 5가지'뿐이다.
- **한 쪽 분량**: A4 한 장(인쇄) / 휴대 기기 한 번 스크롤.
- **단서 → 원인 → 처리**를 짧은 화살표 목록으로(원인 그래프의 축약형).
- **도구 상자 표**에 '되돌릴 수 있음(○ 쉬움 / △ 보통 / ✕ 어려움)'을 붙인다. 접착 매뉴얼이 가장 자세하다(허브).
- **불려 가는 사건** 목록으로 본 팀에서 언제 말해야 하는지 알게 한다.
- **본 팀에 설명할 3문장** 연습 칸으로 개별 책무성을 만든다.
- **미니 퀴즈 3문항**(80분은 앞의 2문항). 모두 맞혀야 '전문가 인증'.

## 2. 구성 요소(JSON 필드)
| 필드 | 내용 |
|---|---|
| `id`, `label`, `shape`, `colorToken` | metal/glass/paint/adhesive, 이름, 배지 모양(●▲■◆), 색 |
| `whoAmI` | 2문장 소개 |
| `clues` | `{clue, cause, action}` 목록(단서 → 원인 → 처리) |
| `keyIdeas` | 꼭 기억할 원리 3~4개 |
| `toolbox` | `{name, use, reversibility: "easy"|"medium"|"hard"}` |
| `calledIn` | `{caseId, role: "lead"|"support", hint}` |
| `explainPractice` | 본 팀 설명용 문장 틀 3개 |
| `quiz` | `{q, options[], answer, why}` × 3 |
| `callouts` | 사건별로 교사 패널 S11에 띄울 핵심 문장 |

## 3. 분야별 요약
| 분야 | 핵심 원리 | 주도 사건 | 보조 사건 |
|---|---|---|---|
| ● 금속 | 녹의 색으로 금속을 알아본다 / 단단히 고르게 덮인 녹은 보호막이 되기도 한다 / 서로 다른 금속이 물·소금과 함께 맞닿으면 한쪽이 빨리 녹슨다 → 사이를 떼어 놓는다 / 소금기·습기를 줄인다 | 1 | 3, 5 |
| ▲ 유리 | 붙이기 전에 번호·사진·위치 그림 / 접착제 없이 먼저 맞춰 보기(가조립) / 작은 조각도 버리지 않기 / 투명한 접착제도 시간이 지나면 누렇게 변할 수 있다 | 2 | 3 |
| ■ 페인트 | 물감 = 색가루(안료) + 풀(교착제) / 두꺼운 칠은 갈라지고 벗겨지기 쉽다 / 성질이 다른 풀을 번갈아 쓰면 벗겨지기 쉽다 / 성분 분석으로 무엇을 썼는지 밝힌다 | 4 | 1 |
| ◆ 접착 | 좋은 접착제 = 잘 붙고 + 나중에 다치지 않게 떼어지는 것 / 고친 부분이 원래보다 너무 세면 나중에 원래 부분이 다친다 / 떼는 도구는 유물보다 무른 것(나무·대나무) / 데우거나 적셔서 무르게 한 뒤 조금씩 | 3, 5 | 1, 2, 4 |

## 4. 정확성 메모(교사·fact-checker용)
- 아교는 따뜻한 물에, 밀가루 풀(전분 풀)은 물에 다시 풀려 비교적 되돌리기 쉽다. 에폭시·순간접착제·시멘트는 되돌리기 어렵다.
- '고친 부분이 원래보다 약해야 한다'는 보존 분야에서 널리 쓰이는 원칙(수리 부분이 먼저 망가지게)으로, 초5 수준으로 단순화했다.
- 청동의 '가루처럼 번지는 연두색 녹'(이른바 청동병)은 소금기(염화물)와 습기가 원인으로 알려져 있다. 사건 1은 구리이므로 매뉴얼의 일반 지식으로만 쓴다.
