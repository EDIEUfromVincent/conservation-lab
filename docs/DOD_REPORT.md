## 교사가 수업 전에 입력·확인할 항목

1. 실제 AI 답변의 모델명·캡처 날짜·답변 전문을 교사 패널에 입력한다.
2. 사용할 영상 주소를 확인하여 입력한다. 로컬 영상 파일은 제공되지 않았으므로 실제 로컬 영상 재생은 검증하지 않았다.
3. 학생 기기로 전문가 매뉴얼을 열 경우 접근 가능한 매뉴얼 공유 주소를 입력한다. 주소가 없으면 인쇄물을 사용한다.
4. 숭례문 현황은 원본 자료의 2022년 보도 기준이므로 최신 사실을 확인한다. 여신상 초록 표면 보존의 1차 출처와 교과 성취기준 연결도 교사가 최종 확인한다.
5. 실제 수업 기기·프로젝터에서 수업 전 점검을 한다. 실제 교실 효과, Safari·다른 브라우저, 실제 수업 사진은 이번 검증의 증거에 포함하지 않는다.

## 범위와 인계

- P2 team 모드 및 기기 간 실시간 동기화·듀얼 모니터 기능은 미구현이다.
- 실습 수치는 학습용 근사 모델이며 실제 물성 측정값이 아니다. 유물 그림은 자체 SVG 도식이며 실물 사진을 사용하지 않는다.
- 원본 `data/*.json`의 역사 사실을 변경하지 않았다. Claude 소유 계획 문서와 Grok 소유 서버 설정을 수정하지 않았고 새 서버를 띄우지 않았다.
- 실행 방법은 `docs/RUNNING.md`, 수업 운영은 `docs/TEACHER_GUIDE.md`, 수업안·자산 출처는 `docs/LESSON_PLAN.md`와 `docs/ASSETS.md`를 따른다. 서버 현황은 Grok의 `docs/SERVER.md`를 따른다.

교사 입력·사실 확인 항목은 남아 있지만, 동결된 코드 범위에 대해 실패한 필수 검증은 없다.
