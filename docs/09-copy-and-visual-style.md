# 09. 문구 규칙과 시각 디자인

## 1. 학생 화면 문구 규칙 (초5)
| 규칙 | 기준 |
|---|---|
| 문체 | 해요체. 명령보다 권유("~해 봐요", "~할까요?") |
| 문장 길이 | 한 문장 35자 안팎, 최대 45자. 한 화면 핵심 문장 3개 이내 |
| 한자어 | 처음 나올 때 풀이. 예: 박락(벗겨져 떨어짐), 교착제(색가루를 붙이는 풀), 보존처리(유산을 지키려고 손보는 일) |
| 숫자 | 아라비아 숫자, 단위 붙여 쓰기(80조각, 3일, 약 1,800개) |
| 연도 | "1845년", 세기보다 연도. 지금으로부터 몇 년 전인지 필요하면 괄호 |
| 정답 표현 금지 | '정답/오답/틀렸다' 대신 '해결/악화/되돌릴 수 없음', '더 나은 선택', '다른 길' |
| 인물 | 학생 화면에 실존 인물 이름 금지(교사 노트만). '박물관 기술자', '보존 전문가 팀', '단청 작업 책임자' |
| 비난 금지 | 과거 결정은 "그때는 무엇을 몰랐을까?"로. 조롱·단죄 표현 금지 |

## 3. 시각 디자인
### 3.1 분위기
'보존과학 연구실의 작업 노트' — 따뜻한 종이색 바탕, 차분한 잉크색 글자, 실험 기록지 같은 격자. 화려한 게임 UI보다 '진짜 전문가 도구' 느낌.

### 3.2 색 토큰(예시, frontend-design 단계에서 확정)
| 토큰 | 용도 | 예시 |
|---|---|---|
| `--paper` | 바탕 | #F6F1E7 |
| `--ink` | 본문 | #2B2A27 |
| `--muted` | 보조 글자 | #6B675E |
| `--solved` | ✓ 해결 | #2E7D5B |
| `--worse` | △ 악화 | #B7791F |
| `--irreversible` | ✕ 되돌릴 수 없음 | #B23B3B |
| `--metal` / `--glass` / `--paint` / `--adhesive` | 전문가 | 청록 / 하늘 / 주홍 / 보라 계열 |
- 결과는 **색 + 모양 + 글자** 세 겹으로 구분(색각 이상 대비). 대비비 4.5:1 이상.

### 3.3 기호 체계
| 의미 | 기호 |
|---|---|
| 선택지 카드 A/B/C | ○ / △ / □ (손에 드는 카드와 같은 모양) |
| 결과 | ✓(원 배지) 해결 / △(세모 배지) 악화 / ✕(가위표 배지, 점선 테두리) 되돌릴 수 없음 |
| 전문가 | ● 금속 / ▲ 유리 / ■ 페인트 / ◆ 접착 |
| 단계(원칙) | P1 돋보기 / P2 뿌리 / P3 되감기 화살표 / P4 가위 대신 붓 / P5 증거 카드 |
> 선택지의 △와 결과의 △가 겹친다. 결과 배지는 색 채움 + 글자 '악화'를 반드시 함께 써서 구분한다.

### 3.4 글자
- 무대 기준: 제목 56px, 선택지 40px, 본문 32px, 보조 26px. 휴대 기기(manual 모드): 본문 20px 이상.
- 글꼴: 시스템 한글 글꼴 우선. 내장 시 Pretendard(OFL) 서브셋.

### 3.5 움직임
- 지연 결과의 '시간 빨리 감기' 1.5초, 결과 배지 등장 0.3초 정도. 깜빡임·흔들림은 실습 5의 '탑이 흔들림' 외에는 쓰지 않는다. `prefers-reduced-motion`이면 애니메이션 생략.

## 4. 에셋 목록
| 에셋 | 만드는 방법 | 비고 |
|---|---|---|
| 사건 브리핑 일러스트 5장 | `canvas-design` 또는 직접 SVG | 실제 사진 대신 그림. 실존 인물 얼굴 금지 |
| 증거 카드(X선 느낌, 옛 도면 느낌, 성분 결과지) | `canvas-design` | 학습용 재현 그림임을 작은 글씨로 표기 |
| 녹 질감, 단청 갈라짐 질감, 꽃병 깨짐 무늬 | `algorithmic-art`(p5.js)로 생성 → PNG로 저장해 내장 | 런타임 p5 금지 |
| 미륵사지 증거 카드 1~6층 | 직접 SVG(도면 느낌) | 실제 1910년대 사진은 저작권·출처 확인 전 사용 금지 |
| 전문가 배지 4종, 원칙 아이콘 5종 | 직접 SVG | 단색으로도 구분 가능 |
| 예시 문화유산 카드 6장(S03) | 직접 SVG 일러스트 | 전국 고르게 |

### 이미지 사용 원칙
- 공공누리 제1유형 이미지는 출처 표기 후 사용 가능. 박물관 소장품 사진은 이용 조건을 확인하기 전 사용하지 않는다.
- 유명 문화유산(자유의 여신상, 투탕카멘 가면 등)은 실루엣·단순화된 일러스트로 그린다.
